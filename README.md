# Router configurations

These files transcribe the `show running-config` outputs supplied for the Packet Tracer project.

- `R4.txt` — Tunis
- `R5.txt` — Bizerte
- `R6.txt` — Sfax

The configurations are preserved as supplied. Review the ACL on R6 before presenting this repository as a validated security configuration: its source/destination networks and wildcard masks differ from the 10.6.x.x VLAN addressing shown on R6. No correction has been applied here.
